# Publish the redesign

1. Open `https://github.com/rishuvro/rishuvro`.
2. Upload the `assets` folder to the repository root.
3. Replace the existing `README.md` with the new `README.md`.
4. Commit with: `Redesign GitHub profile homepage`.
5. Refresh `https://github.com/rishuvro`.

Important: GitHub profile READMEs cannot run custom JavaScript or arbitrary CSS. This redesign therefore uses GitHub-compatible Markdown/HTML, SVG artwork, badges and dynamic stat cards.
